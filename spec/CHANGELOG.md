- 0.1.3 (2026-10-20): 04 — `origin` bound to the token subject (`sub` or `<sub>/...`). No fixture change.
- 0.1.4 (2026-10-21): 06 — flow `~val` gets optional `deployed_by`. No fixture change.
- 0.1.5 (2026-10-21): 01 — peer broker nodes: downstream sites at `down/<d>`, upstream at `up/<u>` (`wy:broker`, `attr.root`, `connected`); `up/` is no longer a reserved virtual prefix. No fixture change.
- 0.1.6 (2026-10-22): 02 — UI fields: action `display`, `group`; param-meta `display`, `description`, `placeholder`, `editor` (`password`, `textarea`); fixture `meta_action_ui`.
- 0.1.7 (2026-10-22): 02 — param-meta `editor: "file"` (binary parameter from a local file). No fixture change.
- 0.1.9 (2026-10-22): README rule 4 — the protocol version is `attr.proto` of `wy/<site>/sys/~meta`; `wy/<site>/sys/broker` stays the broker's liveliness token, without a node. No fixture change.
- 0.1.8 (2026-10-22): README rule 6 — nesting of arrays, maps and tags in one value is at most 32; deeper input is `invalid_message`. No fixture change (every fixture is shallower).
- 0.1.10 (2026-10-22): 01, 03, 05 — history: `since=`, `agg` `and|or`, any `<n>s|m|h|d|w` window, `limit` ≤ 100 000; the answer is one or more arrays from the broker's historian (ADR 0014), errors as a status attachment; rights as `subscribe` (session ACL on `~val`), no `history:read` token (owner decision). Fixtures `hist_raw`, `hist_agg` (`HistRow` in both SDKs).
- 0.1.11 (2026-10-23): 02 — `view=list` summaries carry `unit` (key 2) and `writable` (key 4, already sent by the SDK); the UI writes the unit after numeric values. Fixture `meta_view_list` (first child has `2: "°C"`).
- 0.2.0 (2026-10-23, breaking): 01, 06 — site sections under full names: `down` → `downstream`, `up` → `upstream`, `flows` → `dataflows` (owner decision, backlog items 3 and 4). Fixture `ptok_claims_v1` (grant keys). Stored grants and history watches replay under the new names (registry SCHEMA 14, gateway users SCHEMA 4), and the historian's recorded series are renamed when its store opens; deployed flows must be deployed again (their proofs name the old keys).
- 0.2.1 (2026-10-23): 02 — `view=list` summaries carry key 16 `has_history` (true when `attr.history` is not empty); `attr.history` = array of store keys, a key under `wy/<site>/sys/history/` answers at the point's own key (ADR 0016). Fixture `meta_view_list` (second child has `16: true`).
- 0.2.2 (2026-10-24): 01 — site section `storage` (`wy/<site>/storage/**`): broker storage of folders and values people create, as a DSA broker's `/data` (ADR 0017); link id `storage` is reserved. No fixture change.
- 0.2.3 (2026-10-24): 01 — commands from upstream sites: `~set`/`~act` on `downstream`, `dataflows`, `storage` of a site below always, on `sys` only with that site's `allow_config`; tokens carry the target site; `wy/<site>/sys/signing_keys` lists the keys that sign them (ADR 0018). No fixture change.
- 0.2.4 (2026-10-24): 02 — param-meta `editor` values `daterange` (`<from>/<to>` in RFC 3339, with preset ranges), `date` (one instant) and `duration` (seconds, typed in a chosen unit) for UIs. No fixture change.
- 0.2.5 (2026-10-24): 06 — `~def.layout` `{<node_id>: [x, y]}` (editor positions, ignored by the compiler and outside a node's config) and `dataflows/~act/node_types` (the node-type catalog for editors). No fixture change.
- 0.2.6 (2026-10-28): 02 — key 17 `has_nodes` (bool, on a container's `~meta` and in `view=list`): a child without `type` exists, so a tree UI draws a triangle only where it has nodes to show; the responder publishes the container's `~meta` again when it changes. Fixture `meta_view_list` (fourth child, a folder with `17: true`).
- 0.2.7 (2026-10-28): 02 — a site's historian also answers at each watch key (`wy/<site>/sys/history/<group>/<watch>/~val?history=`); a downstream site's point that it records is read there, and its `attr.history` comes from the recording site (`sys/overlays/.sites`, merged by that site's gateway; ADR 0020). No fixture change.
- 0.2.8 (2026-10-28): 04 — status 0x2B `resource_exhausted` (a bound of the callee reached; ADR 0023). No fixture change.
- 0.2.9 (2026-10-31): 01 — `allow_config` of an upstream opens `config` on the whole site below (`downstream`, `dataflows`, `storage` and `sys`), not on `sys` alone (owner decision, ADR 0018 amendment): link actions such as Export, Edit, Stop run from above. No fixture change.
- 0.2.10 (2026-10-31): 04 — optional `ptok` claim `auth`: the caller's full grant set on this site, sent only on `~act/*` tokens, never used to authorize the request; a responder that acts for the caller (DQL, ADR 0025 item 4, owner decision) checks the keys the caller names against it, capped as the effective level and to a limited key's scopes; no `auth` = refused where it is needed. Fixture `ptok_claims_auth`.
- 0.2.11 (2026-10-31): 04 — `jti` is single-use per responder (remembered until `exp`, in memory: a responder restart forgets it), `exp` at most 15 min ahead, a full cache refuses new tokens (ADR 0029, decision 3). No fixture change.
- 0.2.12 (2026-11-01): 04 — the grant lookup comes before the replay check: a token with no grant for the request key is refused and never remembered; one `sub` holds at most a quarter of the replay cache (16 384 live tokens), so one caller cannot lock out the others (security review SDK-1, ADR 0029 decision 3). No fixture change.
- 0.2.13 (2026-11-01): 06 — validation step 9: a `subscribe` or `liveliness` source reads the own site's `downstream`, `dataflows` or `storage` only (security review FLOW-1, ADR 0031). No fixture change.
