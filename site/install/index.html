Studio

Get Studio, separately

Studio ships on its own and never inside a broker image. Install it once on your own machine; it logs in to one gateway with your user and reaches that site and every site below it, within your rights. Edits are staged and applied only when you say so.

  • macOSRuns today, built from the repository. A signed .dmg is planned.From source today
  • WindowsThe next build: an installer per release.Planned
  • LinuxThe next build: x86-64 and ARM64 packages.Planned
  • iOS and AndroidThe app has both targets; store releases come after the desktop.Planned
  • WebNot yet: the client library uses sockets a browser does not have, so the web needs a second transport.Not started
macOS today, with Flutter 3.50 and frx 0.3.7 
git clone https://github.com/gencto/wyrm && cd wyrm/studio
flutter pub get
frx watch                         # code generation; leave it running
cd app && flutter run -d macos
Connecting to your broker On the broker's own machine, Studio uses http://127.0.0.1:8445 with the user admin. From another machine, give the gateway a certificate (tls: "site_ca", or your own tls_cert and tls_key) and use its https:// address. Guide: the broker reference.
Check

Check what you downloaded

Every file of a links release is listed in the release's SHA256SUMS and carries build provenance from GitHub Actions: proof of the workflow and the commit it was built from. A broker checks the SHA-256 of a package itself before it installs one.

curl -fLO {{release_download}}modbus-{{version}}-linux-aarch64.zip
curl -fLO {{release_download}}SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
gh attestation verify modbus-{{version}}-linux-aarch64.zip -R gencto/wyrm
