No standby is following this broker

sys/standby_connected is 0. Either no warm standby is configured, or the one configured cannot reach this broker. If this host fails, the site stops until it is back; links on other machines walk to their next endpoint only if they have one.

To add one (on the hosts, not in Studio) 1. Copy the keys to the second host: wyrmd keys export here, wyrmd keys import there. 2. In wyrmd.json5 on both hosts: standby: {peer, takeover_s, primary, witness} and peers.listen; a lease arbiter on a third host is recommended. 3. Start the second host; this tab shows it within a second.
