WYRM Studio · design system

Dark, dense and calm. One place for every setting.

The tree says where, the workspace says what, the inspector says how. Everything a person edits is staged first and applied once, with their own rights. Built from the WYRM home page: the same ground, the same ember accent, the same IBM Plex faces.
