WYRM Studio · property sheet

Properties are data. One component draws all of them.

Studio never hard-codes a setting. A link package, a peer link between brokers, an action and a flow block each describe their properties in one schema. The property sheet reads that schema and renders it, so a new property ships with the package or the broker, not with Studio.
