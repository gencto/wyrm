5 · Inline, before anything is sent

2 fields to fix
Anything Studio can check from the schema the broker sent (~meta.cfg: required, bounds, enums, patterns) is checked as the user types and shown under the field. The Save button says how many fields are left. No dialog, and no call that the broker would refuse anyway. When the broker still refuses (invalid_parameter naming a field), the Input dialog’s “Back to the form” puts its message under that field and focuses it. Today InstallLinkAction throws “Give the link a name.” as a dialog: that becomes this inline error.
