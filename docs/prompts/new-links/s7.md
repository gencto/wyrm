# Link `s7` — Siemens S7 PLC (S7comm over ISO-on-TCP)

**Why:** Siemens S7-300/400/1200/1500 PLCs are among the most common controllers in plants. Many do not have OPC UA enabled; S7comm (port 102) reads their data blocks directly.

**Scope**
- Connection = a PLC: host, port 102, rack and slot (defaults 0/1 for S7-1200/1500, 0/2 for S7-300), connection type (PG/OP/S7 basic), timeout, PDU size negotiated (show it in a status leaf).
- Device = one CPU (normally one per connection; kept for the framework's three levels and for gateways with several CPUs).
- Point = an address in Siemens notation: `DB10.DBX4.3` (bool), `DB10.DBB5`, `DB10.DBW6`, `DB10.DBD8`, `DB10.DBD8:REAL`, `MW20`, `IB0`, `QX1.0`, `T5`, `C3`, with a data type (BOOL, BYTE, WORD, DWORD, INT, DINT, REAL, LREAL, STRING[n], S5TIME/TIME as seconds, DATE_AND_TIME as RFC 3339) — parse and validate the address at add/edit with a clear error; `scale`/`offset`/`unit`.
- Reads: batch points into "Read Var" requests with as many items as fit the negotiated PDU; merge adjacent addresses in the same area into one item where cheaper; a per-item error return code → that point's error only.
- Writes: "Write Var" per point (bits with the bit transport size, no read-modify-write of whole bytes); read-back.
- TPKT/COTP/S7 header codec in-crate with PDU reference matching (a late reply is dropped).
- Ping: read SZL or a 1-byte read of a configured address; a "not supported" error still means alive.
- Note in the guide: S7-1200/1500 need "PUT/GET access" enabled and non-optimized DBs for absolute addressing; the link reports the PLC's error code text when access is denied.

**Not in scope**: S7comm-plus (the newer protected protocol of 1200/1500 with symbolic access), PLC program upload/download, alarms.

**Crate**: implement in-crate (TPKT RFC 1006, COTP class 0, S7 setup/read/write); a crate may be used only if it is pure Rust, async, maintained and MIT/Apache — no `snap7` C bindings.

**Simulator**: an S7 server in `src/sim.rs` answering setup communication, read var and write var over DB, M, I, Q areas with a byte image per area, with failure modes (item address out of range → item error, silence, connection close, small PDU size to force request splitting).
